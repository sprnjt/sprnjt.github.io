A lightweight retrieval-augmented generation system that splits documents into meaningful segments, indexes them with semantic embeddings and FAISS vector search, and generates grounded answers through either the OpenRouter API or local HuggingFace language models.

Code: [github.com/sprnjt/mini-rag](https://github.com/sprnjt/mini-rag)
